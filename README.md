# Mathias Treats

Customer-facing website for Mathias Treats, featuring cakesicles, cake pops, local pop-up treats, customer reviews, Instagram, and direct WhatsApp ordering.

## Local development

```bash
npm install
npm start
```

Open `http://localhost:4200`.

## Production check

```bash
npm run build
npm test
```

The project uses Angular server-side rendering so public content is available to search engines and social link previews.
